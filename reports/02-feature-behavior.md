## Ограничения Bot API, влияющие на паритет (CONFIRMED, docs.bot API)

- Бот может писать пользователю только если тот запускал бота → рассылки и
  напоминания доставляются нативно только «активированным» клиентам;
  остальным мастер получает готовый текст для ручной отправки (полный
  аналог поведения оригинала 4.4).
- Глобальный лимит ~30 сообщений/с → рассылки чанками.
- Отправка заблокирована → Bot API 403 → пометка клиента «недостижим».
