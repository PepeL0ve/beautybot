# beautyBOT — Telegram-бот для бьюти-мастеров (клон функционала BeautyAgent)

Clean-room реализация по методологии REA. Платформа: Telegram Cloud serverless (@tgcloud).

## Структура

| Путь | Что это |
|---|---|
| `reports/` | REA-доказательства (шаги 1–2): поведение оригинала, платформа |
| `spec.md` | Behavior-only спецификация — **единственный вход для билдера** (шаг 3) |
| `docs/manual-tests.md` | Ручные чек-листы приёмки по фазам |
| `bot/tgcloud/` | Код бота: `schema.js`, `lib/` (логика), `handlers/` (update-типы) |
| `bot/scripts/` | Локальные тесты чистых модулей (`node scripts/test-time.mjs`) |
| `comparison.md` | (шаг 5 REA) оригинал vs клон — появится в Фазе 6 |

## Фазы

0. ✅ Каркас: схема БД, доступ по белому списку, онбординг мастера, меню, движок слотов (13 групп локальных тестов)
1. ✅ Ядро календаря: каталог услуг (CRUD, сортировка, «цена от», популярные), рабочие часы по дням,
   перерывы/выходные/личные дела, шаблоны расписания, ручные записи (создание с выбором свободного слота,
   перенос, отмена/завершение/неявка, предоплата, цена, заметка, удаление), виды «День» и «Неделя».
   Проверено: 21/21 интеграционных тестов на живой БД + сквозные UI-сценарии в облаке.
2. ✅ CRM клиентов: список с фильтрами (все/новые/постоянные/потеряшки/ЧС/архив) и пагинацией,
   поиск по имени/телефону/username, карточка с историей визитов и статистикой, авто-категории,
   группы клиентов, чёрный список, архив, редактирование полей, удаление с каскадной очисткой.
   Проверено: 16/16 интеграционных тестов на живой БД + сквозные UI-сценарии (включая T19).
3. ✅ Онлайн-запись клиентом через бота: визитка по deep link, выбор услуги → дата → слот,
   подтверждение мастером (✅/❌), авто-подтверждение, «только для своих», чёрный список,
   «Мои записи», отмена клиентом, лист ожидания, отзывы ⭐1–5.
   Проверено: 19/19 интеграционных тестов + полный UI-флоу двух аккаунтов (T7–T12).
4. ✅ Напоминания и рассылки: /tick + внешний cron, sweep просроченных напоминаний
   (запись за 24ч/2ч, «потеряшки», дни рождения, предложения из листа ожидания),
   рассылки чанками с отчётом, настройки мастера, блокировка бота.
   Проверено: 12/12 интеграционных тестов + UI-флоу настроек/рассылок.
5. Финансы и статистика
6. Итерация (сравнение с оригиналом, полировка)

## Obsidian

Папка `obsidian/` — вольт Obsidian с планом, прогрессом и решениями:

- `plan.md` — архитектура, фазы, ключевые решения
- `progress.md` — текущее состояние (обновляется скриптом)
- `spec.md`, `reports/`, `manual-tests.md` — копии из корня
- `decisions/` — архитектурные решения (ADR)
- `roadmap.canvas` — визуальный трекер фаз

Синхронизация из проекта: `node scripts/sync-obsidian.mjs`.
Откройте `obsidian/` как vault в Obsidian для просмотра.

## Работа с ботом

```bash
cd bot
npx tgcloud login     # один раз: CLI-токен из @BotFather (бот → Serverless)
npx tgcloud push      # деплой кода
npx tgcloud migrate   # применить изменения схемы БД
npx tgcloud run handlers/message '{"message":{...}}'  # проверка модуля без деплоя
node scripts/test-time.mjs  # локальные тесты слотов/таймзон
```

Напоминания: внешний cron каждые 5 минут шлёт боту `/tick` в чат администратора
(настраивается в Фазе 4; на платформе нет планировщика — см. reports/03).
