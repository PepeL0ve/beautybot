# beautyBOT — проект в Obsidian

Эта папка — зеркало проекта в Obsidian. Откройте её как vault:
Obsidian → Open folder as vault → `C:\Users\FLYXSE\beautyBOT\obsidian`

## Структура

- `plan.md` — план проекта (фазы, статус, архитектура)
- `progress.md` — текущая фаза, что сделано, что дальше
- `spec.md` — спецификация (копия, обновляется из корня)
- `reports/` — REA-доказательства (копия)
- `decisions/` — ключевые архитектурные решения
- `comparison.md` — оригинал vs клон (появится в Фазе 6)
