# REA Report 01 — Целевое приложение: общий обзор (шаг 1 "Look")

Дата: 2026-11-03
Метод: публичные источники (лендинг), clean-room — описывается только поведение.

## Что за приложение

Онлайн-сервис (лендинг + мобильные приложения iOS/Android/RuStore) для частных
мастеров бьюти-индустрии и небольших салонов: планировщик расписания, приём
онлайн-записей от клиентов, база клиентов, напоминания/рассылки, учёт финансов.

- Позиционирование: «ассистент мастера», замена бумажным блокнотам.
- Две персоны: **мастер** (управляет всем через мобильное приложение) и
  **клиент** (записывается через публичную страницу онлайн-записи мастера).
- Модель монетизации: пробный период 30 дней, далее подписка.

## Пять функциональных блоков (CONFIRMED, лендинг)

1. **Календарь / планировщик** — рабочее расписание, личные дела,
   автоматическое формирование ближайших свободных окон, отправка свободных
   окон клиентам / готовые сторис для соцсетей, шаблоны настройки расписания
   на недели и месяцы вперёд.
2. **Онлайн-запись** — клиент видит только окна/дни, разрешённые мастером;
   запись доступна 24/7 даже когда мастер занят; фото и описания услуг.
3. **База клиентов** — ведение базы, авто-категоризация по поведению визитов,
   группы клиентов, история посещений, массовые рассылки.
4. **Личный ассистент** — уведомления о заявках с сайта, напоминания о сеансах
   и о клиентах-«потеряшках»; готовые тексты с автоподстановкой данных
   клиента, отправка через мессенджеры/SMS.
5. **Финансы** — наглядная информация по посещениям, доходам, расходам и
   прогнозу прибыли.

## Отличие нашей реализации (решение по проекту)

Оригинал: мастер в мобильном приложении, клиент на веб-странице.
Наш клон: **оба через одного Telegram-бота** — мастер управляет ботом,
клиенты записываются по deep link в того же бота. Платформа запуска:
serverless Telegram Cloud (@tgcloud), см. reports/03-platform.md.
