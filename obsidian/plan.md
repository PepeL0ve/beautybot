# План проекта

Клон функционала BeautyAgent (beautyagent.ru) как Telegram-бот.

## Цель

Мастер бьюти-индустрии управляет записями, клиентами, рассылками и финансами
через Telegram. Клиенты записываются по ссылке мастера прямо в этом же боте.

## Архитектура

- **Платформа**: Telegram Cloud serverless (@tgcloud) — JS ESM без npm в рантайме,
  `sdk/db` SQLite (без FK), хендлеры = файлы в `bot/tgcloud/handlers/`
- **Доступ**: мастера регистрируются только по белому списку (`access_list`)
- **Напоминания**: внешний cron каждые 5 минут → `/tick` в чат админа
  (на платформе нет планировщика)
- **Деньги**: целые копейки (integer)
- **Время**: unix-секунды для абсолютных моментов, `YYYY-MM-DD` + минуты от
  полуночи для локального календаря мастера

## Ключевые решения

- Клиенты записываются через тот же бот (не отдельный Mini App)
- Мультиарендность: один бот — много изолированных мастеров
- Тестирование на живой БД через временные `endpoints/tN.js` → `tgcloud run`
- Все тексты интерфейса в `lib/i18n/ru.js` (разметка HTML)
